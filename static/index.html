0.020

Higher values ignore more background noise but can miss quiet speech. Lower values pick up softer voices and more noise.

0.015

Audio below this level counts as silence. Higher values end pauses sooner; lower values can keep breath or hum inside a turn.

100ms

Speech must persist this long to start an utterance. Higher values reject clicks and short coughs; lower values react sooner.

300ms

The base pause before a complete turn ends. Higher values allow thinking pauses but delay replies. Lower values can cut off a sentence.

950ms

Extra thinking time for incomplete clauses. The effective window never falls below your base silence duration.

320ms

Minimum voiced audio before interruption can be confirmed. Higher values resist accidental interruptions but react more slowly.
