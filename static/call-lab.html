Checking configuration

Install a trusted native Windows FreeSWITCH build, then generate the isolated lab configuration:

python -m tools.setup_freeswitch_lab --host YOUR_LAN_IP
python -m tools.run_freeswitch_lab --freeswitch-dir "C:\Program Files\FreeSWITCH"

The setup prints your SIP password and dashboard token. The launcher starts FreeSWITCH and this server using private configuration files. A gateway health check below confirms whether FreeSWITCH is actually available.
